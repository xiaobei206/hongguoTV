# 红果 TV（hongguoTV）

面向 Android TV、电视盒子和可安装 APK 的智慧屏的红果短剧客户端。项目是个人维护的非官方客户端，与红果及电视品牌厂商无关联。

## 主要功能

- **为遥控器设计的电视界面**：侧边导航、海报网格、清晰的焦点高亮和 D-pad 操作。
- **排行榜与新剧上线**：进入页面后预加载多屏内容，向下浏览时提前续载，并对重复页、空页和无效游标进行有界处理。
- **播放与选集**：Media3 ExoPlayer、CENC 渐进解密、失败重试与诊断；控制栏隐藏时左/右跳转 10 秒、上/下切换上一集/下一集；控制栏显示时方向键移动焦点，选集由独立按钮打开。
- **观看历史与收藏**：确认历史卡片即可从上次的剧集和播放位置继续，不必先绕到详情页。
- **与开心果手机/平板端协作**：支持局域网一次性交接播放任务，以及向手机发送播放诊断。
- **自动更新**：Release APK 附带 SHA-256 校验；下载失败时可切换经过可信摘要校验的 HTTPS 备用源，不关闭 TLS 证书验证。

TV 端与「开心果」手机/平板端独立发布，复用 openhongguo Kotlin 内容模型、红果 SDK 调用链、CENC 解密和 Media3 播放实现；电视界面单独面向遥控器和低内存设备优化。

## 下载

前往 [GitHub Releases](https://github.com/xiaobei206/hongguoTV/releases) 下载最新的通用 APK。对应版本的 SHA-256 校验文件与 APK 一起提供。

## 设备与系统

- 最低 Android 6.0（API 23），单一通用 APK。
- 设计和性能基准包括小米全面屏电视 E55A / E55S、东芝 75U6900C，以及可安装 Android APK 的华为智慧屏。
- 不同电视固件对应用安装、遥控器按键和硬件解码器的处理可能不同；CI 构建通过不代表所有机型已经完成实机验收。

## 构建

需要 JDK 17 和 Android SDK 36。运行以下命令执行单元测试并构建 Debug APK：

    ./gradlew testDebugUnitTest assembleDebug

正式 Release 由 GitHub Actions 构建、签名校验并生成 APK 与 SHA-256 文件。仓库中用于自动化发布的签名材料是公开的，**不能用于安全敏感应用**；相同签名可被任何人使用，因此它不能单独证明 APK 来源。请勿将该密钥复用于其他项目。
